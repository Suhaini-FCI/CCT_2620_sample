AI Career Opportunities

1. AI / Machine Learning Engineer

  • Develops AI and machine learning systems.
  • Solves real-world problems using AI.
  • Relevant certification: Microsoft Azure AI Engineer.
  • Relevant pathway: Google Cloud Machine Learning Engineer.

2. Data Scientist

  • Analyses data to discover useful patterns.
  • Uses statistics and AI to support decision-making.
  • Relevant certification: IBM Data Science Professional Certificate.
  • Relevant pathway: Microsoft Azure Data Scientist.

3. Generative AI / Prompt Engineer

  • Creates and improves prompts for generative AI.
  • Develops AI workflows for organisations.
  • Relevant certification: Microsoft Azure AI Fundamentals.
  • Relevant pathway: Google Cloud Generative AI training.
